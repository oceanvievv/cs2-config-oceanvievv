# cs2-config-oceanvievv

Профили настроек CS2:

- **Home**: 1440×1080, полноэкранный режим, 144 Гц, MSAA 4×, фильтрация 2×.
- **hightab**: 1440×1080, полноэкранный режим, 600 Гц, MSAA 4×, фильтрация 2×,
  средние тени и текстуры, HDR Quality, FSR Disabled (Highest Quality).

Открой `cs2-config.exe`, выбери **Apply profile**, затем профиль и **Apply**.
Профиля по умолчанию нет. Перед применением закрой CS2 и войди в Steam.
Параметры запуска вставь в **Steam → CS2 → Свойства → Общие → Параметры запуска**.

Если частота выше доступной для выбранного разрешения, будет использована
максимальная поддерживаемая с указанием в результате. Сам профиль не меняется.

Чтобы обновить профиль, измени настройки в CS2, выйди из игры, открой
`cs2-config.exe`, выбери **Update profile**, затем профиль и нажми **Save changes** после проверки.
Для нового профиля выбери **Create profile** в меню.

Чтобы переименовать конфиг, выбери **Rename config** и введи новое имя. Название
обновится в сохранённых данных, EXE, заголовках README и окна. Имена профилей,
папки и GitHub-репозитория останутся прежними.

Для переименования профиля выбери **Rename profile**, затем профиль и новое имя.
Настройки сохранятся, ссылки на консольные команды обновятся.

Все настройки находятся в `profiles.json` и встроены в EXE. После обновления
загрузи содержимое папки в свой репозиторий заново. На другом ПК нужен свежий EXE.
Ссылки на консольный вариант для каждого профиля находятся в [README](README.md).
Старые папки cfg, video, machine и cloud-backup новая утилита не использует.

Прицел переведён в пиксельный формат: длина 4, толщина 1, зазор 2,
цвет RGB 50, 250, 250, Half Outline, опорная высота 1080.
Точное визуальное совпадение с прежним прицелом пока не проверено в игре.
